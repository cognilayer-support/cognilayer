# Security Policy

## Verantwortungsvolle Offenlegung

Wir nehmen die Sicherheit unserer Plattform und unserer Kunden ernst.  
Wenn Sie eine Sicherheitslücke in Cognilayer gefunden haben, informieren Sie uns bitte **vertraulich**.

## Meldeprozess

1. **Melden Sie Schwachstellen nicht als öffentliches Issue.**
2. Senden Sie eine E-Mail an: **security@cognilayer.de**
3. Wir bestätigen den Eingang innerhalb von **48 Stunden**.
4. Wir arbeiten an einer Lösung und informieren Sie über den Fortschritt.
5. Nach Bereitstellung eines Fixes stimmen wir die Veröffentlichung mit Ihnen ab.

## Erwartete Reaktionszeiten

| Stufe | Antwortzeit | Fix-Zeit |
|-------|:-----------:|:---------:|
| Kritisch (CVSS 9-10) | 24h | 7 Tage |
| Hoch (CVSS 7-8.9) | 48h | 14 Tage |
| Mittel (CVSS 4-6.9) | 72h | 30 Tage |
| Niedrig (CVSS <4) | 1 Woche | 90 Tage |

## Scope

Folgende Komponenten fallen unter diese Policy:

- Cognilayer Portal (Web UI)
- Cognilayer Public API (`api.cognilayer.de`)
- Self-Hosted Agent (`ghcr.io/cognilayer-support/agent`)
- Cognilayer Front Door / CDN

## Belohnungen

Wir haben derzeit **kein Bug-Bounty-Programm**.  
Auf Wunsch nennen wir Sie im Security-Changelog als Finder.
