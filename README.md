# Cognilayer

> **Cognilayer** ist eine Multi-Tenant SaaS-Plattform für MCP-Server (Model Context Protocol).  
> Betreiben Sie Ihre KI-Server sicher und skalierbar — in der Cognilayer-Cloud oder On-Premise in Ihrer Infrastruktur.

## Self-Hosted Agent

Unser **Self-Hosted Agent** läuft in Ihrer Infrastruktur als Docker-Container:

```bash
# Repository mit Agent-Docker-Image und Dokumentation:
# → https://github.com/cognilayer-support/agent
```

| Ressource | Link |
|-----------|------|
| GitHub Repo | [cognilayer-support/agent](https://github.com/cognilayer-support/agent) |
| Docker Image | `ghcr.io/cognilayer-support/agent:latest` |
| Docker Compose | [docker-compose.yml](https://github.com/cognilayer-support/agent/blob/main/docker-compose.yml) |
